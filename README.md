Sales Data Analysis Project

Project Overview

This project focuses on analyzing sales data using Python and Pandas to understand sales performance across different products, cities, categories, and months.

Objectives

* Clean and prepare the sales dataset.
* Analyze total sales and profit.
* Identify product-wise sales performance.
* Analyze city-wise and category-wise sales.
* Understand monthly sales trends through visualizations.

Tools & Technologies

* Python
* Pandas
* Matplotlib
* Microsoft Excel
* VS Code

Data Cleaning

* Checked missing values.
* Checked duplicate records.
* Cleaned the dataset.
* Exported the cleaned data into a CSV file.

Key Results

* Total Sales: ₹4,84,500
* Total Profit: ₹65,700

Visualizations

* Product-wise Sales
* City-wise Sales
* Category-wise Sales
* Monthly Sales

Project Files

* sales_analysis.py – Python analysis code
* sales_data_analysis.xlsx – Original dataset
* cleaned_sales_data.csv – Cleaned dataset
* README.md – Project documentation

Conclusion

This project helped me practice data cleaning, data analysis, grouping, and data visualization using Python.
